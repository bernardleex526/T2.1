## 二、门控语义：代码推导 vs 旧报告

`outlier_gate.h:140-144`：`innovation_m = |T_k(b_k) − T_{k−1}(b_k)| = |ICP_k(b_k) − (ICP_{k−1}(b_{k−1}) + R_{k−1}·Δb)|`。

- `[观测]` 它是**“本次 ICP 解相对‘上一解 + 里程计推进’的残差”**（滤波新息），**不是物理步长 `v·Δt`**（步长被减掉了），也不是 `map←odom` 平移本身的差。
- `[观测]` 参考是**最后一次被接受的 RAW 候选**（非发布 EMA）；`reset()`/`lost` 重播种会把它设为当前候选。
- `[观测]` 旧报告“新息 0.046–0.139 m ≈ 四足步长 0.086 m”的前提**被否定**：四足物理步长 @10 Hz 实测 mean 0.0506 / p95 0.1013 / max 0.1235 m；@2 Hz 更新周期约 0.25 m/更新。
- `[条件]` **里程计单独可解释的新息**：其数值（0.5 s 位移误差 RMSE 0.01228 / max 0.0455 m；里程计轨迹自身刚体对齐残差 RMSE 0.0244 m）来自 0.5 s 差分；reviewer R17 指出该差分**未对齐实际门控事件/最后接受参考/杆臂实体**，因此**不能**据此把被拒新息分解为“ICP 抖动”，也**不得**当作新门限依据。**放宽门限的建议维持“无证据支持”。**

## 三、TF 语义：`map←odom` 冻结 ≠ `map←body` 冻结（R13/R15/R17）

- `[观测]` `traj/tf_map_odom.tum`：3549 行 / 293 时戳，四元数+平移**只有一个取值**（`max|Δ|=0`），= 初始锁定值；`record_traj.py` 为纯 `/tf` 订阅者，恒定非录制伪影。
- `[观测]` 但合成位姿 `map←body = map←odom ∘ odom←body`：路径 **30.394 m**、首末净位移 **5.838 m**（GT 重叠段 30.277 / 5.861 m）⇒ **`map←body` 全程随里程计运动**。
- `[观测]` 旧报告 18.98 m 是**整条轨迹的一个固定刚体错位**：估计轨迹 ≈ GT 旋转 **122.44°**、平移 2.226 m（位置拟合残差 RMSE 0.0247 m）；误差随离锁定点距离**先升后降**（0.21→23.46→10.08 m），**不是随时间累积的漂移**。
- `[BLOCKED]` **该 122.44° 是位置轨迹层面的刚体变换分量，不是姿态真值误差**（R17）；其归因涉及至少四处候选（操作员初值朝向 / `T_mocap_map`|杆臂对 B 的适用性 / 里程计-姿态关系 / 组合链），现有产物不可判定。
- `[BLOCKED]` **“恒定 `map←odom` ⇒ 丢掉的 316 个里程计位姿不改变 ATE”不成立**（R15）：恒定只保证同一时戳的组合关系相同；位置误差随轨迹位置变化，筛采样会改变 RMSE 权重。撤回“不影响 ATE”，293 子集 ATE 不等于 609 全集 ATE，且缺完整集合重算。
