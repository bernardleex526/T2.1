1. **物理速度 ≠ 播放倍率**：`--rate 0.5` 只改 CPU 接收节奏，**不改变**记录中的物理速度/角速度/冲击。**禁止**用降倍率虚构“低速满足”。
2. **速度统计口径必须随数字**：
   - DatasetQualification 口径（固定 1.0 s 滑窗、首末真实样本弦位移、**不插值**）：`tuhh_night_09` 窗口**均值 1.560 / 中位 1.714 m/s**。
   - 旧文档口径（逐样本差分）：均值 1.655 / 中位 1.722 m/s。
   - 两者**不矛盾**，但**必须带口径引用**；旧文档“89.8% >1 m/s”在任何产物中无记录（同口径独立复算为 89.63%）。
3. **目标工况仅由用户给定**：0.5–1.0 m/s。DatasetQualification 初稿“≥30 s 连续有效段（G2）”“只认 Livox MID-360”两项门限**未获授权，已被主审驳回**；修订稿改为**资格各轴独立报告 + 速度段客观报告，30 s 仅作敏感性**，**不得**据此写“不存在验收集”。Livox 族含 **Mid-70**。
4. **重访“0”只是选定判据下的 0**，不能宣称物理上无重访。
